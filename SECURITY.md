# Security

Do not report security vulnerabilities in a public issue.

Email **security@seatlayer.io** with a description, reproduction steps, and the
affected SDK version. Do not include SeatLayer secret keys, customer data, or
live booking credentials in the report.

The packages in this repository are browser integration wrappers. SeatLayer's
renderer, designer, booking services, and other production runtime components
are maintained privately and distributed as compiled artifacts.
